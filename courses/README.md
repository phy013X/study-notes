## 新增一门课怎么做

1. 新建英文短名文件夹，如 `os/`、`algorithms/`、`database/`；
2. 在文件夹里放 `README.md` 作为该课程的索引页（可复制 [`../templates/topic.md`](../templates/topic.md) 的结构）；
3. 每篇笔记一个 `.md` 文件，如 `os/process-scheduling.md`；
4. 回到本文件和仓库根 [README.md](../README.md) 的「知识地图」各加一行链接；
5. 在来源日记的「🔗 沉淀」处补上指向这篇笔记的链接。
