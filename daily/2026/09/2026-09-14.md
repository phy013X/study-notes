## 💻 编程 / 技术
- 设计了学习日志仓库的整体结构：`daily/` 每日流水账 + `courses/`、`tech/` 等主题沉淀区，周末把日记里学透的内容整理过去。
- 走了一遍 Git 工作流：`git init` → 提交 → `gh repo create` 创建公开仓库并推送。
- 把 ACCV 2026 的 LaTeX 模板（本质是 Springer LNCS 格式）改造成了**通用中文技术文档模板**：
  - 脱离 LNCS 会议格式，改用标准 `article` + `ctex`；
  - 支持中文、数学公式、定理环境、代码高亮、三线表；
  - 参考文献用 `biblatex` + `gbt7714` 国标格式，XeLaTeX 一键编译。
  - 模板位置：[templates/latex-report-template/](../../templates/latex-report-template/README.md)

## 📝 收获与疑问
- 今日搞懂了：
  - GitHub 网页原生渲染 LaTeX 公式（`$...$`）和 Mermaid 图表，Markdown 笔记不需要任何构建工具；
  - 论文会议模板的格式文件（`.cls`/`.sty`）投稿时不能改，能改的只有正文 `main.tex`；
  - `listings` 宏包对中文支持不好，代码注释要中文的话得上 `minted`。
