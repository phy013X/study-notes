## 软件工程项目是什么

- 一个目录，一组文件，一个可交付的文件。
- 目录的文件混合了 intent,spec, impl
- build之后可以的得到可交付的东西，如本地窗口，exe文件。
- 软件 = 数据 + 程序 + 文档

## git保存软件开发过程中的版本

- 持久的数据化结构
- git clone ：从远处下载代码
- git add ：把代码添加到本地
- git commit ：提交代码
- git可视化网站[https://learngitbranching.js.org/]和[https://code.cs61a.org/]
- commit message标准：类型+范围+行为变化，一个change对应一个意图。
