# tech · 课外技术

课堂之外学到的技术：工具、编程语言、框架、踩坑记录。**一个主题一个文件夹**。

## 索引

| 主题 | 笔记 |
|---|---|
| （示例）Git | [git/README.md](git/README.md) |

## 可以放什么

- 工具用法与配置：Git、Linux、Docker、VS Code……
- 语言/框架深入笔记：Python、Java、Spring、React……
- 环境搭建、报错排查的踩坑记录（这种未来的自己最感激）
- 读书 / 读官方文档的技术总结

写法和课程笔记相同：主题文件夹 + `README.md` 索引 + 单篇 `.md`，
模板用 [`../templates/topic.md`](../templates/topic.md)。
