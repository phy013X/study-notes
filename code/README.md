# code · 代码练习

完整可运行的代码放在这里。**几行的小片段直接写在笔记的代码块里，不必放这。**

## 三种去处

1. **几行片段** → 直接写当天日记或主题笔记的代码块中；
2. **算法练习 / 小实验** → 按主题建子目录，如 `code/algorithms/`、`code/leetcode/`；
3. **成型的小程序 / 课程设计** → 按 `日期-名字` 建目录，如 `code/2026-09-20-http-server/`，
   并在当天日记里写一段说明：它解决什么问题、怎么运行。

## 约定

- 文件名英文小写 + 短横线；每个稍大的程序目录里放一个 README 说明运行方法；
- 依赖较多的项目写明语言版本和安装命令；
- 课程作业代码**公开前先确认任课老师态度**（避免学术诚信争议），拿不准先不提交；
- 数据集、大文件不要放进 Git（仓库根 `.gitignore` 已默认忽略常见类型）。
